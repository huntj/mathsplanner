# @mathsplanner/gallery

A React and Vite app for browsing every statement × depth × numbers setting × seed. Search and filter the 686 statements, follow their prerequisites both ways, and view any statement's generator at any depth, numbers setting and seed, with answers, misconceptions and worked solutions on request. Every view's URL is a complete question key (`#/s/Y5-GEO-04?depth=1&numbers=standard&seed=42&v=0.1.0`), so a link always regenerates the same question. Run it with `pnpm gallery`; pushes to `main` deploy it to GitHub Pages at https://mathsplanner.jedhunt.co.uk/. Still to come: pull request preview sites and recording the review checklist.
