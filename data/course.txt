# The Learn Maths course: the path pupils follow in apps/learn, one section per year.
# "=== Name {stage}" starts a section, holding every skill of that stage. "## Name {unit-id} [topic]"
# starts a unit of 3 to 8 skills, coloured by its topic from topics.txt. Each line under it is a
# skill (a sub-statement, or a statement with none), then its wording, which is only there to
# read: `pnpm data:course` refills it from statements.json and writes data/course.json.
# Skills are learnt in the order listed, so a skill must come after any it needs in the same
# section. `pnpm data:course --draft Y8 "Year 8"` prints a first draft of a new section.
