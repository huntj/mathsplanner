# @mathsplanner/marking

Marks a student's response against a part's `AnswerSpec` and returns the score, any matched misconception and the feedback to show. It covers numeric tolerance and accuracy, exact symbolic equivalence (via the Cortex Compute Engine), required forms such as simplest form or a√b, choices, ordering, matching, plotting and validator-checked open answers. It runs in the browser and does not need to know how the question was generated. Implementation starts in Phase 5.
