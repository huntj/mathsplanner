# @mathsplanner/render

Turns a `Question` object into an accessible HTML string with no browser dependency: maths through KaTeX with HTML and MathML output (bad LaTeX throws rather than reaching students), options for choice, order and match answers, and, on request, answers, misconceptions and the worked solution. `questionStyles` holds the base CSS. The gallery, the practice app and the print tool all use it, so a question looks the same everywhere. Diagrams come from `@mathsplanner/diagrams`; a diagram that contradicts its numbers throws, and types the engine does not draw yet show a labelled placeholder.
