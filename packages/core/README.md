# @mathsplanner/core

The foundation every generator builds on: the `Statement` and `Question` schema types and the statement ID scheme; `Rng`, a seeded random source (cyrb128 hashing into sfc32) so every question is reproducible from its key; exact rationals with BigInt (`frac`), including mixed numbers, rounding and recurring decimals; exact surds (`sqrt`, `surd`), including rationalising denominators of the form p + q√r; LaTeX helpers (`latex`, `toLatex`, `bracket`, `term`, `expression`); and `defineGenerator`, which wraps a generator with seeding, retries and checks, plus `createRegistry`, which attaches statement metadata. Polynomials, angle and triangle builders, "nice" number pickers and unit conversion will be added as the generators that need them are written.
