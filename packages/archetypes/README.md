# @mathsplanner/archetypes

The fifteen question patterns (standard, missing-value, reverse, varied-form, match-representations, choose-the-diagram, draw-or-plot, spot-the-mistake, explain-the-error, always-sometimes-never, true-or-false-why, odd-one-out, compare-methods, open-construction and multi-step-context) and the shared solution-step builders. A generator supplies the maths; an archetype builds the stem, answer options, marking and solution layout. Code is MIT; archetype text is CC BY 4.0 (see `LICENSE-CONTENT` at the repository root). Implementation starts in Phase 4.
